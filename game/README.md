# Production Game

Godot **4.7.2 stable** project, created after verifying the local portable engine.

`scenes/app/bootstrap.tscn` loads the validated original Blender pipeline sample, a 2.5D floor, orthographic camera and a small safe-area-aware label. Mobile renderer; landscape; 1366×768 reference viewport. No gameplay definitions or hero production are included.

`tests/foundation_test.gd` checks version/settings, deterministic vectors and scene/skeleton/animation loading headlessly. `scripts/core/foundation_rng.gd` is a harness fixture, not approval of the final gameplay RNG.

Runtime GLB is generated by `tools/asset_pipeline/build_sample.py`; its bytes must match the validated export and provenance receipt. `.godot/` is a disposable import cache. Commit `.gd.uid` and `.glb.import` metadata; do not commit caches.

`export_presets.cfg` intentionally has no export presets until Android SDK/export templates and platform signing are configured. See `docs/qa/FOUNDATION_VALIDATION.md` for reproducible commands and limits.
