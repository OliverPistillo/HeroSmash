## Shared unresolved differences

- UI shop=3; helper/probability=4. No-selling UI; latent sell API remains. Economy constants alone do not resolve these contracts.
- preGold=0 falls through to current gold in JS. Player loss HP uses its own pre-loss streak/enemy level; bot loss uses winner streak/round.
- Player/bot periodic effects, on-hit procs, critical opening charges and healBoost differ. New isolated operators are actor-symmetric, with explicit deterministic input ordering.
- JS Toxin ticks are continuous dt-scaled, stacks cap at 20 and durations refresh; canonical stack application does not adopt these values without a status specification.
- All numbered levels are rejected by the pilot runtime. Generic legacy level parameters are preserved without interpreting them as exact effect scaling.
