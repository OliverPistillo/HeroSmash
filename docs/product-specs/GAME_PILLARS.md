# Hero Smash — Game Pillars

## 1. Build decisions matter

The market phase should create meaningful tension between:
- immediate power;
- branch thresholds;
- rarity;
- economy;
- rerolling;
- future scaling.

## 2. Fights must be readable

The player should understand why they won or lost without reading a combat log.

Animation, VFX, status indicators and recap should expose the important causes.

## 3. Short-session mobile rhythm

Preparation is active and tactical.
Combat is short, spectacular and mostly automatic.
The loop returns quickly to the next decision.

## 4. Strong fighter identity

Every hero needs:
- recognizable silhouette;
- personality;
- readable combat style;
- branch affinity;
- distinct signature animation/VFX language.

## 5. Depth without interface clutter

The game may have complex card/branch interactions, but the presentation should remain compact and touch-friendly.

## 6. Data-driven balance

Balance decisions should be informed by large simulation batches and telemetry-compatible metrics.

## 7. Original identity

Inspirations may guide pacing or system analysis.
Production visuals, names, characters, brand and UI must belong to Hero Smash.
